# Embedded Learning
A structured, hands-on journey to rebuild and develop my embedded systems knowledge from the fundamentals.

This repository grows gradually with my actual learning progress. A topic is added only when I begin studying and practicing it.

## Objectives
- Build a strong foundation in C programming.
- Understand digital logic and microcontroller fundamentals.
- Practice peripherals such as GPIO, interrupts, timer, PWM and ADC.
- Learn UART, I2C, SPI and CAN communication.
- Understand RTOS concepts through practical exercises.
- Explore Embedded Linux with Raspberry Pi.
- Develop debugging skills using real tools.
- Build complete embedded projects.
